# The built-in framework symbol list of the non-copyable analyzer.
# Format: one documentation-comment ID per line, with an optional marker (";new", ";borrows", ";drains", ";owned", ";borrowswhen=" with outcomes, ";view", ";noncopyable", ";unsafetocopy", ";copyable", ";erasable", ";clones" or ";clones=complete") and optional ";for=" type parameter names. The outcomes of "borrowswhen" are "true" and "false". The line of a static field ("F:") takes no marker.
# A symbol list file of a project can also vouch for an assembly, with a line of the form "A:Assembly.Name;trusted".
# Runtime source read: dotnet/runtime d757c03be2c3. What in that source backs each entry is in NonCopyableSymbols.evidence.md beside this file.
# A line ending in "# net11+" names a member that exists from .NET 11 on. It does not resolve in a project that targets .NET 10.
# A line ending in "# netfx" names a symbol that only the .NET Framework has. It does not resolve in a project that targets .NET.
#
#
# "borrows" also answers who keeps a container. A parameter whose type mentions a type parameter that is not marked is taken to
# keep the container that it is given, since no declaration tells ArrayPool`1.Return, which keeps its array, from Array.Reverse``1,
# which only uses it. Every member of this list with such a parameter was read in the runtime source. One that only uses what it is
# given during the call is marked "borrows". One that hands it back, as a reference, a ref struct, another type or an "out"
# argument, needs no marker: what it hands back is followed. One that is left without a marker keeps: constructors,
# ArrayPool`1.Return and Task.Run.
#
# "borrowswhen=false" says that a member keeps nothing of a value that it is given by value where it returned false, and has taken
# it where it returned true or threw. Each member that has it returns false before it keeps anything of the item, which the comment
# above it shows.
#
# Members of Unsafe, MemoryMarshal, CollectionsMarshal, ImmutableCollectionsMarshal and Marshal are listed for one fact only:
# they make no copy. What they let code do that the language otherwise rules out (write through a read-only reference, hold a
# null reference, keep a view past a change of its collection) is outside what the analyzer guarantees: see "Not covered".

# "unsafetocopy" marks a struct whose copy can break memory safety: free, unpin or reach memory twice or after it is gone. Under the
# updated memory safety rules a copy of one is an error. "noncopyable" marks one whose copy breaks only the logic of the program.
#
# The handles. Free and Dispose clear the handle field of the instance that they are called on, and then free the slot of the
# runtime's handle table that the field named, with no check that the slot is still the one that was allocated. A copy keeps the old
# value: its Free or Dispose releases a slot that may by then belong to another object, or unpins memory that a pointer from
# AddrOfPinnedObject or GetAddressOfObjectData still points into. GCHandle<T>.Target reads the slot with Unsafe.As<T>, so a copy
# read after the slot was given to another object hands out that object as a T.

# ============================================================================
# Hand-over between tasks and threads (basic members only)
# ============================================================================
#
# Every member here was read in the runtime source for what it does with a value. A write moves the value into one place: the
# buffer, a reader that is waiting, or, in a bounded channel that drops, the callback for dropped items. A read takes it out, and
# nothing is left behind that another read could hand out, so those are marked "new". A peek and an enumerator hand out a copy
# of what the collection still holds, so they are listed with no marker and get a warning on a stored collection.
#
# A write that returns false has not taken the value: TryWrite returns false only before it does anything with the item, and the
# TryAdd of a blocking collection only where no room came up in time. A write that throws may have taken it, as any member may.
#
# Every TryWrite of the framework's channels returns false only where the channel is done writing, or full in the mode Wait,
# before it does anything with the item. The writers of the five channels are the only ones of the framework; a writer of another
# library is taken to do what the documentation of TryWrite says, "true if the item was written; otherwise, false if it wasn't
# written". Read at v10.0.0 (BoundedChannel.cs, RendezvousChannel.cs, AsyncOperation.cs), and the five TryWrite at v10.0.0 and
# v11.0.0 (with UnboundedChannel.cs, SingleConsumerUnboundedChannel.cs and UnboundedPriorityChannel.cs).
#
# A note for a maintainer: TryWrite and WriteAsync can throw after the channel took the item. The callback for dropped items of a
# bounded or rendezvous channel runs outside the lock and lets its exception through, and a reader that is completed with the item
# runs its continuation at once where the channel allows synchronous continuations.
#
# A sequence that takes each element out as it is enumerated is marked "drains": ChannelReader`1.ReadAllAsync is an iterator
# around WaitToReadAsync and TryRead, and BlockingCollection`1.GetConsumingEnumerable one around the TryTake of the collection
# that it wraps. Nothing is left behind that a second enumeration could hand out again, so the sequence is a new container
# whatever it was called on. An enumerator of such a sequence holds its current element until it moves on, like any other.
#
# Not here: what copies every element (ToArray, CopyTo, the constructors from a sequence, PushRange), and what compares values
# with the default comparer, which boxes a copy of each (TryUpdate, TryRemove of a pair, AddOrUpdate).

# ============================================================================
# Classes that clone themselves: their own code clones an object with MemberwiseClone
# ============================================================================
#
# "clones" says that the class's own code clones an object of it field by field, so an object of any class that derives from it can
# be copied, a non-copyable value in one of its fields with it. A class of a project that derives from one of these, at any depth,
# gets a warning on each field that holds a non-copyable value (SCA1009), a GCHandle or another built-in non-copyable type included.
# One line covers the class that makes the call and every class that derives from it, so the framework classes that inherit the call
# (every Encoding, every Calendar, every XmlSchema type) need no line of their own for that. A type parameter of a class that derives from one,
# bound to a non-copyable type, gets the warning where it is bound.
#
# A "clones" line for a member, a method, a property or an event, says that the member clones its object, or the object that it is
# given, field by field, or hands it to code that can, directly or through other members; for an event, where a handler is added or
# removed. A warning then never advises a symbol list line
# that says the member makes no copy, and such a line of a symbol list file is left out. "clones=complete" on the line of a class
# says that its "clones" lines name every member of it that clones its object or hands it on: a member that no line names is taken
# to do neither, and a use of it on an object whose class binds a non-copyable type gets no warning unless its signature shows that
# it can hand the object on (see the lines with no marker below). A class that no "clones=complete" line names has every member that
# no line names counted as one that can clone. "clones=complete" counts wherever a line says it: a plain "clones" line for the same
# class, here or in a symbol list file, takes nothing away.
#
# The members of the Xml classes were not analyzed, so XmlSchemaObject and XmlQualifiedName are not marked "clones=complete", and
# every member of them and of the XmlSchema classes counts as one that can clone. A symbol list file can mark them where its author
# vouches for their members.
#
# FrameworkScanTests reads the IL of every assembly of Microsoft.NETCore.App, Microsoft.AspNetCore.App and
# Microsoft.WindowsDesktop.App, of .NET 10 and .NET 11, and of the .NET Framework 4.8.1 where it is installed. It finds every call
# of MemberwiseClone on "this" or on the argument of a static member of the class, and fails for a class that another assembly can
# derive from and that has no line here, neither of its own nor of a base class. It follows the calls from the members of every class whose chain reaches one of these to the members that
# clone, and fails for a public or protected member that clones its object or one that it is given and has no line. And it follows
# where the object of each member can reach other code, and fails for a member that has neither a line nor an entry in the evidence
# that says why it hands nothing on. What clones in each class is in NonCopyableSymbols.evidence.md, under Classes That Clone Themselves;
# what reaches other code, and the judgements that the scan makes there, are under Members Whose Own Object Reaches Other Code.
