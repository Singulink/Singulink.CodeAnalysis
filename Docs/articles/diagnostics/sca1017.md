# SCA1017: Field That Is Unsafe to Copy in a Struct That Does Not Say So

Mark a struct that holds a field of a type that is unsafe to copy `UnsafeToCopy = true`.

## Example

```cs
[NonCopyable]
public struct Session
{
    private NativeBuffer _buffer;               // SCA1017: a copy of Session copies the buffer
}

[NonCopyable(UnsafeToCopy = true)]
public struct OwnedSession
{
    private NativeBuffer _buffer;               // OK
}
```

## How to Fix

- **Add `UnsafeToCopy = true`** to the `[NonCopyable]` attribute of the struct, as the message says.
- **Hold the value by reference** instead, in a class or an array, if the struct is not meant to own it.

## Details

A struct declares an instance field whose type is [unsafe to copy](../guides/marking-a-struct.md#unsafe-to-copy), and its own `[NonCopyable]` attribute does not say `UnsafeToCopy = true`. A copy of the struct copies the field, so the struct is unsafe to copy as well. The analyzer reads that from the declaration of the struct and never works it out from its fields, so the struct says it itself. Until it does, the struct is what its attribute says: a plain non-copyable type.

| Field | Gets the warning |
|---|---|
| A struct that is unsafe to copy, such as `NativeBuffer` | Yes |
| A nullable, a tuple or a generic struct over one, such as `NativeBuffer?` or `(NativeBuffer, int)` | Yes |
| A parameter of a primary constructor that members of the struct use, which the compiler keeps in a field | Yes, at the parameter |
| `NativeBuffer[]`, a class, or a `List<NativeBuffer>` | No: the field holds the value by reference |
| A type parameter of the struct, or a type over one such as `T?` | No: each constructed type of the struct is judged by its type arguments |

A struct that is not marked `[NonCopyable]` at all gets [SCA1010](sca1010.md) for such a field instead, whose message names `UnsafeToCopy = true`, so one edit fixes both.

Under the current memory safety rules of C# this is an ordinary warning, like every report of the analyzer. Under the [updated memory safety rules](../rules/updated-memory-safety-rules.md) it is an error, which marking the field `safe` turns into a warning.
