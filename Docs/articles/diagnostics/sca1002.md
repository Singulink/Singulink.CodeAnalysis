# SCA1002: Copy by Return

Do not copy a non-copyable value by returning it.

## What It Means

A method or property returns the value of a field or a reference by value, or a lambda, a local function, an iterator or a member of a type with
a primary constructor returns a variable that lives on after it, or a method returns a variable that a `finally` or the end of a `using` scope
uses after the `return` has read its value. Return by reference, or return a local, a by-value parameter, a new value or a moved value.

## Example

```cs
LockGuard Get() => _guard;                     // SCA1002

LockGuard Take() => NonCopyable.Move(ref _guard); // OK
ref LockGuard Get() => ref _guard;             // OK: returns a reference
```
