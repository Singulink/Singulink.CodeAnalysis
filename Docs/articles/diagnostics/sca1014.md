# SCA1014: Async or Iterator Member of a Non-copyable Struct

Do not make an instance member of a non-copyable struct async or an iterator.

## What It Means

A non-copyable struct has an instance member that is `async` or an iterator, an accessor included. The compiler copies `this` into the state
machine of such a member, so it runs on a copy of the struct and what it changes is lost. It also runs later, on a copy that is out of date
by then, which is why a `readonly` member is reported as well. Do the work in a member that is neither, which can return the task of a
static method, or in a static method that is given what it needs, such as a static iterator over an array of the struct. A
`readonly struct` is not reported: no copy of it can differ from the original.

## Example

```cs
// In a [NonCopyable] struct:
public async ValueTask DisposeAsync() { await ReleaseAsync(_lock); _lock = null; }                // SCA1014: clears a copy

public ValueTask DisposeAsync() { var held = _lock; _lock = null; return ReleaseAsync(held); }    // OK
```
