# SCA1007: GetObjectValue

Do not use RuntimeHelpers.GetObjectValue.

## What It Means

<xref:System.Runtime.CompilerServices.RuntimeHelpers.GetObjectValue*?displayProperty=nameWithType> returns a clone of a boxed struct, field
by field, so it copies every non-copyable value that the struct holds. For any other object it returns the object itself. Every use is
reported, a call and a method group alike, whatever the type of the argument: nobody calls it on something that cannot be a boxed struct.
Use the object as it is.

## Example

```cs
object clone = RuntimeHelpers.GetObjectValue(box);               // SCA1007
Func<object, object> cloner = RuntimeHelpers.GetObjectValue;     // SCA1007

object same = box;                                               // OK: the object itself
```
