# SCA1013: Interface Member Left to Its Default Implementation

Implement every interface member in a struct of a non-copyable type.

## What It Means

A struct of a non-copyable type leaves a member of one of its interfaces to the default implementation of the interface, also one that a
derived interface gives. A call of that member runs on a boxed copy of the value, also through a constrained type parameter. Implement the
member in the struct. A member that is not `virtual` cannot be implemented, so a struct of a non-copyable type cannot implement an interface
that has one. A generic struct that is non-copyable only through its type arguments is reported where it is bound to a type parameter that is
constrained to the interface.

## Example

```cs
interface IReleasable
{
    void Release() { }                         // a default implementation
}

[NonCopyable]
struct Lease : IReleasable { }                 // SCA1013: a call of Release runs on a boxed copy

[NonCopyable]
struct Lease : IReleasable { public void Release() { } }   // OK
```
