# SCA1026: Type That Is Unsafe to Copy for a Type Parameter That Does Not Take One

Do not use a type that is unsafe to copy, or a container of one, for a type parameter marked `[NonCopyable(UnsafeToCopy = false)]`.

## Example

```cs
public struct Scoped<[NonCopyable(UnsafeToCopy = false)] T>
{
    private T _value;
}

var a = new Scoped<LockGuard>();               // OK
var b = new Scoped<NativeBuffer>();            // SCA1026: Scoped<T> does not take a type that is unsafe to copy
var c = new Scoped<List<NativeBuffer>>();      // SCA1026: other code can reach a NativeBuffer through the list
var d = new Scoped<List<LockGuard>>();         // OK
```

## How to Fix

- **Use a type through which no value that is unsafe to copy can be reached** for the type parameter.
- **Use a generic whose type parameter takes any non-copyable type,** one marked `[NonCopyable]` without the property. If the generic is yours, drop `UnsafeToCopy = false` from its mark.
- **Mark the type parameter that you pass on** `[NonCopyable(UnsafeToCopy = false)]` as well, where the type argument is a type parameter of your own generic.

## Details

A type parameter marked `[NonCopyable(UnsafeToCopy = false)]` is a plain non-copyable type inside its generic. Every report about it there gets the ordinary warning, which the author of the generic can suppress: a copy of a value, and a use that hands one to other code. So the generic takes no type through which other code could reach a value that is [unsafe to copy](../guides/marking-a-struct.md#unsafe-to-copy):

| The generic does not take | Example |
|---|---|
| A type that is unsafe to copy | `NativeBuffer`, `(NativeBuffer, int)` |
| A container of one, at any depth | `List<NativeBuffer>`, `Dictionary<int, NativeBuffer>`, `NativeBuffer[]`, `Task<List<NativeBuffer>>` |
| A tuple or a struct that carries one | `(LockGuard, List<NativeBuffer>)` |
| A delegate or another class over one | `Func<NativeBuffer>` |
| A type parameter of the generic around the use that can stand for one, or a type over it | `T` or `List<T>`, where `T` is marked `[NonCopyable]` without `UnsafeToCopy = false` |

A container of a plain non-copyable type, such as `List<LockGuard>`, is taken. A type parameter that is not marked is a copyable type in its own generic, and is judged where that generic is used.

The type is reported wherever it reaches the type parameter:

| Where | Example |
|---|---|
| A member of the generic that is used with it | `new Scoped<NativeBuffer>()`, a static member, a member of a nested type, a call with type arguments written or inferred |
| A static field of the generic, read or written, which runs its static constructor and the initializers of its static fields | `Cache<NativeBuffer>.Shared`. A constant runs nothing and gets no warning |
| A method group that is made into a delegate | `RefAction<NativeBuffer> action = Take;` |
| A base type or an interface, with it as a type argument or at any depth inside one | `class Pool : Base<NativeBuffer>`, `class Runner : Runner<Scoped<NativeBuffer>>` |
| A type that the `new()` constraint lets a generic create | `Make<Cell<NativeBuffer>>()` |
| A struct over it that is boxed | `object boxed = default(Scoped<NativeBuffer>);` |
| Other generic code that it is given to, as a type argument or at any depth inside one, written or inferred. That code can run its members: `ToString`, `Equals` and `GetHashCode` through any type parameter, a static abstract or virtual member through a constraint, and the members of the elements of a collection | `Show(ref scoped)`, `Run<Scoped<NativeBuffer>>()`, `list.Count` on a `List<Scoped<NativeBuffer>>` |
| A field of a struct that holds it inline, where the struct does not override both `Equals` and `GetHashCode`: the ones that it inherits run the members of its fields. A `ref struct` is not reported, since no code can call those on it | `struct Pool { Scoped<NativeBuffer> _scoped; }` |

A use that already has a report about the same type parameter gets no second one. A member that is not on the symbol list, as `List<T>.Contains` with `Scoped<NativeBuffer>`, gets [SCA1020](sca1020.md) instead, which is just as strict.

Naming the type runs no code of the generic and gets no warning: a field, a parameter or a local of type `Scoped<NativeBuffer>` or `List<Scoped<NativeBuffer>>`, `typeof` and `default`. A member that is used on the value does.

Under the current memory safety rules of C# this is an ordinary warning, like every report of the analyzer. Under the [updated memory safety rules](../rules/updated-memory-safety-rules.md) it is an error.
