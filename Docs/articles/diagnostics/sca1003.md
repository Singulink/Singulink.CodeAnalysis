# SCA1003: Use Where the Value May Be Copied

Do not use a non-copyable value where it may be copied.

## What It Means

A stored value is used where it may be copied: passed by value, also as the receiver of an extension method that takes it by value, put in a
tuple, an array or an interpolated string, captured as the receiver of a delegate, used in a `using` statement or as the operand of `with`,
or looked into through `?.` or a pattern with a member that is not `readonly` while it is in a nullable. The result of an assignment that
is used in one of these ways is a read of its target, as in `Take(_held = guard)`. The message names what takes the
copy. A hole of an interpolated string takes its value like a parameter that takes it by value, so a new value, and a local at its last
use, is moved into it. So is an argument for an `in` or `ref readonly` parameter that is not a variable, which the compiler copies into a
temporary (see [Read-only references and temporary copies](../concepts/read-only-references.md)). A use that the analyzer does not
know to be safe is reported under the same ID, with a message that names the kind of operation. An operation that the analyzer has no
judgment for is a stored value where it is used by value: `__refvalue(reference, LockGuard)`, a pointer dereference and an element through a
pointer, the call of a function pointer, and any kind of operation or of pattern that a later compiler adds, until the analyzer is taught
it. Used in place, such an operation is what it is.
One such use is an `await foreach` whose enumerator returns, from `MoveNextAsync` or `DisposeAsync`, an awaitable of its own that is not a
task of the framework and carries a non-copyable type or a container: the members that await it are not given to the analyzer. Pass
by reference, or move the value.

It is also what a value is reported as, new or stored, that the compiler passes on twice: to every target of combined delegates, to
`operator false` and on for a user-defined `&&`, to a method and to the constructor of its interpolated-string handler, to the getter and
the setter of an indexer in a compound assignment. See
[Where the compiler uses one value twice](../concepts/compiler-copies.md). And it is what a pattern is reported as that
uses a part of a value and also takes or uses the value around it: see
[Patterns, deconstruction and tuples](../concepts/patterns.md).

## Example

```cs
Take(_guard);                                  // SCA1003: passed by value

Take(NonCopyable.Move(ref _guard));            // OK
Look(in _guard);                               // OK: passed by reference
```
