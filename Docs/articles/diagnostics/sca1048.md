# SCA1048: Member Nested Too Deeply

Break up code that is nested too deeply to be checked.

## What It Means

A member is nested too deeply for the analyzer, which walks an expression by recursion and stops before the stack runs out: a chain of
thousands of operators, hundreds of nested `?:`, a thousand chained calls. The member is not checked, and a copy in it is not reported; this
finding says so, at the member, so that a member that is not checked never looks clean. The other members are checked as usual. Break up the
expression, with locals or with methods of its own.

## Example

```cs
string Join(string a) => a + a + a + a + /* ... thousands more ... */ a;   // SCA1048: the member is not checked

string Join(string a)                                                 // OK: built in steps
{
    var builder = new StringBuilder();
    for (int i = 0; i < 5000; i++) builder.Append(a);
    return builder.ToString();
}
```
