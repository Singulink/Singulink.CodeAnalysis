# SCA1040: Mark Not Kept Against a Base Member

Keep a `[NonCopyable]` or `[RequiresCopyable]` mark, do not add `[Borrowed]` or `[Kept]`, and neither add nor drop `[MovedFrom]`, against a base member or a delegate.

## What It Means

A `[NonCopyable]` or `[RequiresCopyable]` mark is not kept by a derived type, an override or an implementation, `[RequiresCopyable]` is
added by the copy constructor of a derived record, or `[return: Borrowed]` or
`[Kept]` is added where the member that is overridden or implemented, or the delegate that a method is converted to, does not have it. See
[Marking a type parameter](../guides/marking-a-type-parameter.md), [Returning a container](../concepts/returning-containers.md) and
[Keeping a container that is passed in](../concepts/keeping-containers.md).

`[MovedFrom]` is kept in both directions: an override, an implementation, or a lambda or a method group that is converted to a delegate,
has it on exactly the parameters on which the member that it stands for has it. See [Moving a value](../guides/moving-a-value.md). A
member or a delegate of an assembly that was not built with the analyzer has no mark that counts, so an override or a lambda that adds
`[MovedFrom]` against it is reported even where it carries the mark, and the message says that the mark does not count there. See
[Code Not Built With the Analyzer](../concepts/unchecked-code.md).

`[RequiresCopyable]` on a static constructor or a finalizer is reported here as well: the runtime runs both, so the mark has no use at
which a copy could be reported, and the body is checked as if it were not there.

## Example

```cs
public delegate void GuardsSink(List<LockGuard> guards);
public delegate void KeptSink([Kept] List<LockGuard> guards);

GuardsSink onCreated = registry.Add;           // SCA1040: 'Registry<T>.Add(T)' keeps what it is given
KeptSink keeping = registry.Add;               // OK: the delegate says that it keeps
```
