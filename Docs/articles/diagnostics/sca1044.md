# SCA1044: Conditional Attribute of the Analyzer

Do not declare an attribute of the analyzer as conditional.

## What It Means

One of the analyzer's attributes is declared `[Conditional]`. The compiler leaves a conditional attribute out of the assembly unless its
symbol is defined, so the marks hold inside the project and are gone for every project that uses it. Remove `[Conditional]`. It is also
reported at every use of such an attribute that a referenced assembly declares, where none of its symbols is defined: the mark is missing
from the assembly that is being built. Use the attribute of the `Singulink.CodeAnalysis` package, or declare one that is not conditional.
An attribute that derives from a conditional class is conditional too, and so is a class that derives from <xref:Singulink.CodeAnalysis.NonCopyableAttribute>, which
marks like it. See [Marking a struct](../guides/marking-a-struct.md).

## Example

```cs
namespace Singulink.CodeAnalysis;

[Conditional("DEBUG")]                         // SCA1044: the mark is gone from the built assembly
[AttributeUsage(AttributeTargets.Struct | AttributeTargets.GenericParameter, Inherited = false)]
internal sealed class NonCopyableAttribute : Attribute;
```
