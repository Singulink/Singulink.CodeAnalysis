# SCA1030: By-value Read From a Stored Container

Do not read a non-copyable value by value from a stored container.

## What It Means

A member on the safe list, an `await` or a `foreach` hands out a non-copyable value by value from a stored container, which still holds the
original, or from a view, which never owns its elements. See [What a listed member hands out](../concepts/listed-members.md). Read from a
new value, take the value out with a member that removes it, use a reference, or move the container first.

Where the container is a local that is not the method's own, the message says what made it so, as in
`'list' is not the method's own anywhere in the method, because on line N a lambda or a local function uses it`. A constructor that
creates a non-copyable value over a
stored container, such as `new ValueTask<LockGuard>(_task)`, hands out no copy by itself, and its message is worded for that: the new
value reads what the stored one still holds.

## Example

```cs
LockGuard first = guards[0];                   // SCA1030: a copy out of the list

CollectionsMarshal.AsSpan(guards)[0].Dispose(); // OK: in place
if (held.Remove(key, out var taken)) taken.Dispose();   // OK: taken out
```
