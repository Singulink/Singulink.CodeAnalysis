# SCA1025: Unchecked Assembly That Uses a Non-copyable Type

Build an assembly that uses a non-copyable type with the analyzer.

## What It Means

An assembly that the project references was not built with the analyzer, and it references an assembly that declares a non-copyable
type. A call is judged by the member that it binds to, so the code of such an assembly is not seen where it runs behind a type of checked
code or of the framework: where it implements an interface or an abstract class of a checked library, where it made a delegate or a
function pointer that the project calls, or where it reads an object of a checked class that holds a non-copyable value. That code can
copy a value of the non-copyable type, and no call site shows it. It can name the type only where its assembly references the assembly
that declares it, so the finding is reported for that reference, once for each assembly, and has no place in the source.

A type counts that a `[NonCopyable]` mark makes non-copyable, or that a `noncopyable` line of a list file of the project names where the
type is of checked code, and that no `copyable` line takes out. The built-in non-copyable types of the framework do not count: every
assembly references the framework, and that part stays out of reach (see
[What Stays Out of Reach](../concepts/unchecked-code.md#what-stays-out-of-reach)). The assembly that declares the type can be checked or
not, and a reference to an assembly that forwards the type to it counts as well.

An assembly ends up unchecked in a few ways:

- **The library that it uses kept the analyzer to itself**, with `PrivateAssets="all"`, which is the default for the analyzers package.
  See [Libraries](../guides/libraries.md).
- **Its build turned the analyzers off**, with `RunAnalyzers` or `RunAnalyzersDuringBuild` set to `false`.
- **It is written in another language**, or references the assembly and not the package.
- **It was built with a version of the analyzer from before the marker.**

## What to Do

- **Build the assembly with the analyzer.** Where it is a project of the solution or a library of your own, reference the analyzers
  package there, or let the library that declares the type pass the analyzer on.
- **Vouch for the assembly** where it cannot be built with the analyzer and its code makes no copy of the non-copyable values that it
  gets at, also behind a type of checked code or of the framework. A line of a list file of the project names it by its simple name:

  ```
  # NonCopyableSymbols.txt: the plugins only pass the leases on
  A:Contoso.Plugins;trusted
  ```

  The line turns off this finding for that assembly and changes nothing else: its members stay unchecked code for every other rule. A
  line that has no effect is reported (`SCA1042`): one for an assembly that the project does not reference, that was built with the
  analyzer, or that references no assembly that declares a non-copyable type.

A finding with no place in the source can be suppressed only for the whole project, in `.editorconfig` or with `NoWarn`, which would
leave out every assembly that is added later. The `trusted` line is for one assembly.
