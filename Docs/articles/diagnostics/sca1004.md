# SCA1004: Boxing a Stored Value

Do not box a stored non-copyable value.

## What It Means

A stored value of a non-copyable type is converted to `object` or an interface, which boxes a copy of it. A new value can be boxed: the box then
holds the only instance. See [Boxes](../concepts/conversions.md#boxes).

## Example

```cs
object copy = guard;                           // SCA1004: boxes a copy of a stored value

IDisposable held = myLock.Enter();             // OK: the new guard moves into the box
held.Dispose();                                // runs on the box
```
