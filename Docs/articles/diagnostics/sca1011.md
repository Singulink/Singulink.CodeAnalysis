# SCA1011: Auto-property of a Non-copyable Type

Do not declare an auto-property of a non-copyable type.

## What It Means

An auto-property has a non-copyable type. Its getter returns a copy of the backing field. Use a field, or a property that returns a reference.

Two things that are auto-properties without being written as one are reported with a text of their own:

- **A member of an anonymous type,** where the object is created: `new { Name = name, Lock = myLock.Enter() }`. Every written read
  of such a member is a copy of a field, and what the compiler writes for the type copies it with nothing written: its `ToString`,
  `Equals` and `GetHashCode`, and `with`, which makes a second object. Use a tuple, or a class with a field.
- **A positional parameter of a record,** also where the record declares the member itself as a property that returns a reference:
  the `Deconstruct` method that the compiler writes for the record reads the member by value. Declare the `Deconstruct` method
  yourself, or give the type an ordinary constructor.

## Example

```cs
public LockGuard Guard { get; set; }           // SCA1011: the getter returns a copy

public LockGuard Guard;                        // OK: a field
public ref LockGuard Guard => ref _guard;      // OK: a property that returns a reference
```
