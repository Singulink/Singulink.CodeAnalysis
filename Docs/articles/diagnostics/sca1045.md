# SCA1045: NonCopyableAttribute Outside Its Namespace

Declare NonCopyableAttribute in the namespace Singulink.CodeAnalysis.

## What It Means

An attribute class named <xref:Singulink.CodeAnalysis.NonCopyableAttribute> is declared in a namespace other than `Singulink.CodeAnalysis`, or an attribute class is
named `NonCopyable` with no suffix in any namespace, or a struct or a type
parameter of the project is marked with such a class that a referenced assembly declares. The attributes are recognized by their full name,
so the struct is copyable, and the type parameter is not marked, with no finding anywhere else. Declare the class in the namespace
`Singulink.CodeAnalysis`, or use the attribute of the `Singulink.CodeAnalysis` package. A project that keeps such an attribute on purpose,
for another tool, suppresses the finding. A class of the name that is no attribute is not reported, and neither are the other five names:
an attribute of one of them that is not recognized only means more findings. On a struct of a referenced assembly such a mark is
recognized, and nothing is reported. A class that derives from such an attribute is used like it. See
[Marking a struct](../guides/marking-a-struct.md).

## Example

```cs
namespace MyApp;

[AttributeUsage(AttributeTargets.Struct)]
internal sealed class NonCopyableAttribute : Attribute;   // SCA1045: not recognized in this namespace
```
