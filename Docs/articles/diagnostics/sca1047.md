# SCA1047: NotNullRef on a Method of the Project

Verify a method with a `[NotNullRef]` parameter, then suppress this finding on it.

## What It Means

A parameter that the project declares is marked `[NotNullRef]` where the mark counts. The analyzer does not check that the method
returns only if the reference that it is given refers to something, and what it reports about a `[MovedFrom]` parameter and about a
commit at the end of a `try` block rests on that. Verify and test the method, then suppress the finding there, with a `#pragma` or a
`[SuppressMessage]` that says so. It is reported once for each mark, where the attribute stands, and not for a method of a referenced
assembly, such as the two of the attributes package. It has an ID of its own, so that suppressing it leaves `SCA1046` standing. See
[A reference that is known to refer to something](../guides/null-references.md).

## Example

```cs
internal static class Ensure
{
#pragma warning disable SCA1047 // Verified and tested: it throws for a null reference and does nothing else
    public static void RefersToSomething<T>([NotNullRef] ref readonly T reference, [CallerArgumentExpression(nameof(reference))] string? expression = null)
    {
        if (Unsafe.IsNullRef(in reference))
            Throw(expression);

        static void Throw(string? expression) => throw new NullReferenceException($"The reference '{expression}' is a null reference.");
    }
#pragma warning restore SCA1047
}
```
