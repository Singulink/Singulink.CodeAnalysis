# SCA1005: MemberwiseClone of a Non-copyable Value

Do not call MemberwiseClone on what holds a non-copyable value.

## Example

```cs
class Holder
{
    private LockGuard _guard;
    public Holder Clone() => (Holder)MemberwiseClone();   // SCA1005: the clone has a second guard
}

internal class Base
{
    public Base Clone() => (Base)MemberwiseClone();       // SCA1005: an object of Derived is cloned as well
}

internal class Derived : Base
{
    private LockGuard _guard;
}

public class Shared
{
    private LockGuard _guard;
    public Shared Clone() => (Shared)MemberwiseClone();   // SCA1005: the clone has a second guard; and SCA1008
}
```

## How to Fix

Write the copy out: copy the fields that may be copied, and move or re-create what must not be. <xref:System.Object.MemberwiseClone> makes a shallow copy, field by field.

A field of a class whose base class clones itself, such as <xref:System.Text.Encoding>, gets [SCA1009](sca1009.md) instead, since the call is in code that the analyzer cannot read. Writing the copy out does not answer that warning.

## Details

#### What Gets the Warning

<xref:System.Object.MemberwiseClone> is called in a class that has an instance field of a non-copyable type, its own or inherited, or in a non-copyable struct. A field that holds a container, such as a `List<LockGuard>`, does not count: the clone shares the list. The same warning is given for:

- the clone of <xref:System.MarshalByRefObject>, `MemberwiseClone(bool)`, which <xref:System.IO.Stream> and <xref:System.ComponentModel.Component> inherit;
- a method group of either, as in `Func<object> clone = MemberwiseClone;`, which clones when the delegate is invoked;
- a call on an object of a type parameter, `t.MemberwiseClone()` with `T : Holder`. The analyzer judges it by the class that the type parameter is constrained to, since the object is of that class or of one derived from it.

#### Derived Classes

Where the class has no such field, the object that is cloned can be of a derived class that has one. If a derived class in the same compilation has such a field, the call gets this warning as a definite copy, and the message names that class and its field.

That includes a field of a constructed base class, such as the `T` field of `Box<T>` in `class Derived : Box<LockGuard>`. Where the field holds a captured parameter of a primary constructor, the message names the parameter.

A class that another assembly can derive from also gets a warning for a possible copy, with an ID of its own ([SCA1008](sca1008.md)). It comes together with this warning, whatever fields the class and its derived classes in the compilation have: a derived class of another assembly can hold a value of any type. A sealed class and a struct have no derived class, and get no such warning.
