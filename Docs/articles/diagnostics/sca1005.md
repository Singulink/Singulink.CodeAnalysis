# SCA1005: MemberwiseClone of a Non-copyable Value

Do not call MemberwiseClone on what holds a non-copyable value.

## What It Means

<xref:System.Object.MemberwiseClone> is called in a class that has an instance field of a non-copyable type, its own or inherited, or in a
non-copyable struct. The clone is a shallow copy, field by field. Write the copy out, and move or re-create what must not be copied.

The same is reported for the clone of `MarshalByRefObject`, `MemberwiseClone(bool)`, which <xref:System.IO.Stream> and
<xref:System.ComponentModel.Component> inherit, and for a method group of either (`Func<object> clone = MemberwiseClone;`), which clones
when the delegate is invoked. A call on an object of a type parameter, `t.MemberwiseClone()` with `T : Holder`, is judged by the class
that the type parameter is constrained to, since the object is of that class or of one derived from it.

Where the class has no such field, the object that is cloned can be of a derived class that has one. A derived class of the compilation
that has such a field, its own or one of a constructed base class such as the `T` field of `Box<T>` in `class Derived : Box<LockGuard>`,
is reported here, as a definite copy, and the message names that class and its field. A field that holds a captured parameter of a
primary constructor is named as the parameter. A class that another
assembly can derive from is reported as a possible copy with an ID of its own (`SCA1008`). A sealed class and a struct have no derived
class, and are not reported.

## Example

```cs
class Holder
{
    private LockGuard _guard;

    public Holder Clone() => (Holder)MemberwiseClone();   // SCA1005: the clone has a second guard
}

internal class Base
{
    public Base Clone() => (Base)MemberwiseClone();       // SCA1005: an object of Derived is cloned as well
}

internal class Derived : Base
{
    private LockGuard _guard;
}
```
