# SCA1005: MemberwiseClone of a Non-copyable Value

Do not call MemberwiseClone on what holds a non-copyable value.

## What It Means

<xref:System.Object.MemberwiseClone> is called in a class that has an instance field of a non-copyable type, its own or inherited, or in a non-copyable struct. The
clone is a shallow copy, field by field. Write the copy out, and move or re-create what must not be copied.

## Example

```cs
class Holder
{
    private LockGuard _guard;

    public Holder Clone() => (Holder)MemberwiseClone();   // SCA1005: the clone has a second guard
}
```
