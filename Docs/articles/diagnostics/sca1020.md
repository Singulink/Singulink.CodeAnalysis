# SCA1020: Unlisted Member of an Unmarked Generic

Do not use a member of an unmarked generic with a non-copyable type.

## What It Means

A member of a generic is used with a non-copyable type bound to a type parameter that is not marked, and the member is not on the safe list. See
[Generics that are not marked](../guides/marking-a-type-parameter.md#generics-that-are-not-marked). Mark the type parameter if the generic is yours, add the member to a
[list file](../guides/symbol-list.md) if it makes no copy, or avoid the use.

## Example

```cs
var list = new List<LockGuard>();              // OK: listed
list.Add(myLock.Enter());                      // OK: listed
LockGuard[] all = list.ToArray();              // SCA1020: not listed, it copies
```
