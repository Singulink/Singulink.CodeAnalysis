# SCA1049: UnsafeToCopy Set in the Code of a Mark

Do not set UnsafeToCopy in the code of a non-copyable mark.

## Example

```cs
namespace Singulink.CodeAnalysis
{
    [AttributeUsage(AttributeTargets.Struct | AttributeTargets.GenericParameter)]
    internal class NonCopyableAttribute : Attribute
    {
        public bool UnsafeToCopy { get; set; }
    }

    internal sealed class NativeHandleAttribute : NonCopyableAttribute
    {
        public NativeHandleAttribute() { UnsafeToCopy = true; }   // SCA1049: the analyzer does not read this
    }
}
```

## How to Fix

- **Write the value where the attribute is applied:** `[NativeHandle(UnsafeToCopy = true)]`.
- **Take the value as a `bool` parameter named `unsafeToCopy`,** and set the property from it. The analyzer reads the argument where the attribute is applied: `[NativeHandle(unsafeToCopy: true)]`.

```cs
internal sealed class NativeHandleAttribute : NonCopyableAttribute
{
    public NativeHandleAttribute(bool unsafeToCopy) { UnsafeToCopy = unsafeToCopy; }   // OK
}

[NativeHandle(unsafeToCopy: true)]
public struct NativeBuffer { }   // unsafe to copy
```

## Details

The analyzer reads `UnsafeToCopy` of a mark where the mark is applied, which works for a struct of a referenced assembly as well: the named argument, or an argument for a `bool` parameter of the constructor named `unsafeToCopy`, in any case. It cannot read the code of the attribute class. So a struct marked `[NativeHandle]` in the example counts as plain non-copyable, and a copy of it gets the ordinary warning even under the [updated memory safety rules](../rules/updated-memory-safety-rules.md).

You get this warning in the project that declares the attribute class, for code of that class that sets the value:

| Code | Example |
|---|---|
| An assignment of the property | `UnsafeToCopy = true;` in a constructor or a method |
| The initializer of the property | `public bool UnsafeToCopy { get; set; } = true;` |
| An argument for a parameter named `unsafeToCopy` of another constructor | `: base(unsafeToCopy: true)` |

Setting the property from the constructor's own `bool` parameter named `unsafeToCopy`, or passing that parameter on to another constructor, gets no warning. That is the value that the analyzer reads.

This is a plain warning under both memory safety rules, which every suppression reaches.
