# SCA1042: Line of a Symbol List

Fix the line of the safe list file.

## What It Means

A line of a `NonCopyableSymbols.txt` file cannot be parsed, has an ID that cannot be a documentation comment ID, names a type parameter
after `for=` that the member does not have, or that more than one type parameter of the member and of the types that contain it has, or
has a marker on something that it does not fit: `view`, `noncopyable` or `copyable` on anything but a
struct, `erasable` on anything but a generic class or interface, `new` or `borrows` on a type, `drains` on anything but a method whose
result is an <xref:System.Collections.Generic.IEnumerable`1> or an <xref:System.Collections.Generic.IAsyncEnumerable`1>, `owned` on anything but an instance property of a class whose type is
<xref:System.Threading.Tasks.Task`1>. Such a line is ignored. It is also reported for a `noncopyable` line of a list file of the project that names no type
of the compilation, which would leave the type copyable, and for a `copyable` line that has no effect: one that names no type, one for a
struct that the project declares itself, and one for a struct that nothing makes non-copyable by itself. Fix the ID, or take the line out of the file of a project that does not reference
the type. See [The safe list](../guides/symbol-list.md).

## Example

```
M:ThirdParty.Bag`1.Take;noncopyable             # SCA1042: the marker 'noncopyable' is for a type
T:ThirdParty.Handel;noncopyable                 # SCA1042: names no type of the compilation

M:ThirdParty.Bag`1.Take;new                     # OK
T:ThirdParty.Handle;noncopyable                 # OK
```
