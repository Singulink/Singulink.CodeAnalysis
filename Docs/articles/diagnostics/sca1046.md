# SCA1046: NotNullRef Where It Does Not Count

Put `[NotNullRef]` on a reference parameter of a method that is not virtual.

## What It Means

`[NotNullRef]` stands where it does not count: on a by-value parameter; on a parameter of a virtual or abstract member, an override, a
member of an interface, a delegate, a lambda, an operator, a constructor or an accessor, or on the receiver of an extension block; or
on a parameter of a method that is `[Conditional]` or a partial method with no body, which the compiler can leave out of a build. The
mark counts only on a `ref`, `in`, `ref readonly` or `out` parameter of a method that is not virtual, or of a local function, where a
call names the code that runs. A call of what is reported here proves nothing. See
[A reference that is known to refer to something](../guides/null-references.md).

## Example

```cs
static void Check([NotNullRef] LockGuard guard) { }       // SCA1046: a by-value parameter

static void Check([NotNullRef] ref LockGuard guard) { }   // counts (and is reported as SCA1047 until verified)
```
