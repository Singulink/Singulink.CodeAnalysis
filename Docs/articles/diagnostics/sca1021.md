# SCA1021: Member That Requires a Copyable Type

Do not use a member that requires a copyable type with a non-copyable type.

## What It Means

A member marked `[RequiresCopyable]` is used with a non-copyable type, or a type whose parameterless constructor is marked is bound with one to
a type parameter that has the `new()` constraint. A constructor of a class that calls a marked constructor of its base class with nothing
written uses it too, and is reported where it is declared, or at the name of a class that has no constructor. A `with` on a record uses
the copy constructor of the record and of its base records. See
[Marking a type parameter](../guides/marking-a-type-parameter.md). Use a member that does not copy.

## Example

```cs
public sealed class Pool<[NonCopyable] T> where T : struct
{
    [RequiresCopyable]
    public T[] ToArray() => /* ... */;
}

LockGuard[] all = pool.ToArray();              // SCA1021: ToArray requires a copyable type
int[] numbers = new Pool<int>().ToArray();     // OK
```
