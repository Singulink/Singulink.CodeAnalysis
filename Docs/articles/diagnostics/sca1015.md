# SCA1015: Awaiter of a Non-copyable Type

Do not await with an awaiter of a non-copyable type.

## What It Means

An `await` has an awaiter of a non-copyable type. When the `await` suspends, the compiler stores the awaiter in a field of the state machine,
calls `OnCompleted` or `UnsafeOnCompleted` on the local that it copied it from, and calls `GetResult` on the field when the method resumes. So
what `OnCompleted` takes out of the awaiter is still in the copy that `GetResult` sees. It is reported whatever the awaited type is. Make the
awaiter a class, or a copyable struct that refers to the state. See [Where the compiler uses one value twice](../concepts/compiler-copies.md).

## Example

```cs
[NonCopyable]
public struct LeaseAwaiter : INotifyCompletion
{
    public bool IsCompleted => false;
    public void OnCompleted(Action continuation) { }
    public void GetResult() { }
}

public struct LeaseAwaitable { public LeaseAwaiter GetAwaiter() => default; }

await new LeaseAwaitable();                    // SCA1015: the awaiter is copied into the state machine
```
