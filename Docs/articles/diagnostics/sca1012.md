# SCA1012: By-value Parameter of an Iterator

Do not give an iterator that returns a sequence a by-value parameter of a non-copyable type.

## What It Means

A method or a local function with `yield` that returns a sequence has a by-value parameter of a non-copyable type. The compiler keeps the
arguments of an iterator in the object that it returns and copies them into every enumerator, so what the iterator does with the parameter
runs on a copy, once for each enumeration. The by-value receiver of an extension block is such a parameter of every iterator in the block,
and is reported at the iterator. Create the value inside the iterator, or pass an object that holds it. An iterator that returns an
enumerator (<xref:System.Collections.Generic.IEnumerator`1>, <xref:System.Collections.Generic.IAsyncEnumerator`1>) keeps its arguments once, and is not reported. Neither is a by-value parameter of an
`async` method: the compiler keeps it in the state machine once, and the method works on that one place.

## Example

```cs
IEnumerable<int> Read(LockGuard guard) { /* ... */ yield return 1; }   // SCA1012: every enumeration gets a copy of 'guard'

IEnumerable<int> Read(Session session) { /* ... */ yield return 1; }  // OK: an object that holds the guard
```
