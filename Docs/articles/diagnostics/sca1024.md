# SCA1024: Non-copyable Value Given to Unchecked Code

Do not give a non-copyable value other than by value to code that was not built with the analyzer.

## What It Means

A member of an assembly that was not built with the analyzer gets at a value of a non-copyable type other than by value: by `ref`, `in`
or `ref readonly`, inside a container, inside a view or through a pointer, as an argument, as the receiver of an extension, as an operand
of an operator or a conversion, or through the `Invoke` of a delegate type that such an assembly declares. Nothing checks what the member
does with the value, so it can copy it. A container that is passed to it is no longer the caller's own afterwards.

If the member uses what it is given during the call and keeps nothing of it, add its ID with `borrows` to a list file of the project, as
the message says. Otherwise pass the value by value, which moves it, or avoid the use. A member of the non-copyable type itself is
trusted with its receiver and with values of that type, and a member whose parameter mentions a type parameter goes by the rules of
generic code (`SCA1020`) instead.

## Example

```cs
ThirdParty.Leases.Inspect(ref _lease);                  // SCA1024
ThirdParty.Leases.Fill(leases);                         // SCA1024: 'leases' is a List<Lease>, and no longer the method's own

ThirdParty.Leases.Take(NonCopyable.Move(ref _lease));   // OK: passed by value, so moved
_lease.Release();                                       // OK: a member of the non-copyable type itself
```

```
# NonCopyableSymbols.txt: the member only reads the lease during the call
M:ThirdParty.Leases.Inspect(ThirdParty.Lease@);borrows
```
