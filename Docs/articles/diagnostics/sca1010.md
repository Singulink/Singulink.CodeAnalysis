# SCA1010: Field in a Copyable Struct or a Record

Do not declare a field of a non-copyable type in a copyable struct or a record.

## What It Means

A struct that is not itself non-copyable has a field of a non-copyable type, or a record has one. Copying the struct would copy the field, and a
record copies its fields in `with` and in the members that the compiler writes for it. A parameter of the primary constructor of a copyable
struct that its members use is such a field as well. A static field is not reported. Mark the struct `[NonCopyable]` too, or make it a class
that is not a record.

## Example

```cs
struct Session(LockGuard guard) { public void Close() => guard.Dispose(); }   // SCA1010: 'guard' is a field of a copyable struct

[NonCopyable]
struct Session(LockGuard guard) { public void Close() => guard.Dispose(); }   // OK
```
