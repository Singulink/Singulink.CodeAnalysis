# SCA1022: Container Used as an Untyped Collection

Do not use a container of non-copyable values as an untyped collection.

## What It Means

A container is used as <xref:System.Array> or a non-generic collection interface, which hand out boxed copies of the elements: by a conversion, also
one that variance makes of a type argument, by an inherited member, by an override with a wider return type, by a method group or a delegate
that is converted to a delegate, or by the variable of a `foreach`. See [Containers and conversions](../concepts/conversions.md). Keep the
element type visible, for example with a generic interface.

## Example

```cs
IEnumerable untyped = list;                    // SCA1022: hands out boxed copies

IReadOnlyList<LockGuard> typed = list;         // OK: the guard type is still visible
```
