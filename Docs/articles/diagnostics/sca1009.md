# SCA1009: Non-copyable Value Behind a Base Class That Clones Itself

Do not hold or bind a non-copyable value in a class whose base class clones itself.

## Example

```cs
sealed class PinnedEncoding : UTF8Encoding
{
    private GCHandle _pinned;                            // SCA1009: Encoding's Clone copies the handle
    private readonly HandleHolder _holder = new();       // OK: the clone shares the object that holds a handle
}

sealed class HandleHolder
{
    public GCHandle Handle;                              // OK: no class that clones itself is a base of HandleHolder
}
```

The same goes for a non-copyable value that a generic class holds, where the class derives from one that clones itself. The comments show where each warning goes, in the library and in a project that uses it:

```cs
// In a library
public class TaggedCulture<[NonCopyable] T> : CultureInfo
{
    public T Tag;                                        // SCA1009: in the library's own build

    public TaggedCulture(string name) : base(name) { }
}

public static class Cultures
{
    public static TaggedCulture<T> Make<[NonCopyable] T>() => new("en-US");   // SCA1009: in the library's own build
}

// In a project that uses it
sealed class GuardCulture : TaggedCulture<LockGuard>     // SCA1009: CultureInfo's Clone copies the guard in Tag
{
    public GuardCulture() : base("en-US") { }
}

sealed class HolderCulture : TaggedCulture<GuardHolder>  // OK: the clone shares the holder
{
    public HolderCulture() : base("en-US") { }
}

static object Uses(GuardCulture own)
{
    var culture = Cultures.Make<LockGuard>();            // no warning: the type still shows the guard
    var copy = culture.Clone();                          // SCA1009: the clone copies the guard in Tag
    CultureInfo plain = culture;                         // SCA1009: hands the object to code that can clone it
    CultureInfo mine = own;                              // OK: GuardCulture has its warning where it binds LockGuard
    return CultureInfo.ReadOnly(culture);                // SCA1009: ReadOnly clones what it is given
}
```

## How to Fix

- **Hold the value in an object of a class that your class refers to,** as `_holder` does above. The clone copies the reference, and both objects share the one value.
- **Bind a class that refers to the value,** such as `TaggedCulture<GuardHolder>`, instead of the value. Its objects get no warning wherever they are used.
- **Where the message says that no symbol list line says whether the base class's code clones an object,** the base class is of a library that was not built with the analyzer. Add the line that fits what the class does: see [A Base Class That Is Not Known](#a-base-class-that-is-not-known).
- **Where the warning is on a use,** such as `culture.Clone()`, a conversion or a call of `Visit(Action<Document>)`, the use lets other code clone the object. If the member neither clones the object nor hands it on, add a symbol list line for the member that says so. Or, once the class's `clones` lines name every member that does either, write the class's line as `clones=complete`: see [Clones](../rules/symbol-list-format.md#clones). Otherwise avoid the use.
- **Suppress the warning** where no object of the class is ever cloned.

Writing a copy of your own does not answer the warning on a field. The base class's clone copies the field whatever your own code does, and a call of `MemberwiseClone` in your class gets [SCA1005](sca1005.md) besides:

```cs
public sealed class GuardedCulture : CultureInfo
{
    private LockGuard _guard;                            // SCA1009: CultureInfo's Clone copies the guard, whatever Copy does

    public GuardedCulture() : base("en-US") { }

    public GuardedCulture Copy()
    {
        var copy = (GuardedCulture)MemberwiseClone();    // SCA1005: the clone has a second guard
        copy._guard = default;
        return copy;
    }
}
```

#### A Base Class That Is Not Known

A class of a library that was not built with the analyzer may clone itself too, and the analyzer cannot tell. So a class of the project that derives from one gets the warning on each field that holds a non-copyable value, until a symbol list line says what the base class does:

```cs
sealed class PinnedDocument : Contoso.Document   // Contoso was not built with the analyzer, and no line names Document
{
    private GCHandle _pinned;                    // SCA1009: nothing says whether Document clones itself
}
```

| What you know | Line | What it does |
|---|---|---|
| The base class clones itself | `T:Contoso.Document;clones` | The field keeps its warning, since a clone copies it |
| Neither the base class nor a class above it clones its objects | `T:Contoso.Document;clones=none` | The field gets no warning |
| No code of the assembly copies a non-copyable value | `A:Contoso;trusted` | No field behind a class of the assembly gets the warning |

The analyzer cannot check a `clones=none` or a `trusted` line, so write one only for code that you know. See [Clones](../rules/symbol-list-format.md#clones) and [Trusted](../rules/symbol-list-format.md#trusted).

Two kinds of base class need no line. The framework's classes are covered by the [built-in framework symbol list](../rules/framework-symbol-list.md#classes-that-clone-themselves), which names every one of them that clones itself. A class of a library that was built with the analyzer is checked in that library's own build.

A Microsoft library outside the .NET, ASP.NET Core and Windows Desktop shared frameworks, such as WinUI, counts as another library. So does an assembly that only the .NET Framework or one platform has, such as `System.Messaging` or `Mono.Android`.

## Details

Some classes clone their objects field by field with <xref:System.Object.MemberwiseClone> in code of their own, such as the `Clone` method of <xref:System.Text.Encoding>. The clone copies every field of a class that derives from them as well. The analyzer cannot see the call in another assembly, so a `clones` line of the [symbol list](../rules/symbol-list-format.md#clones) names such a class. The [built-in framework symbol list](../rules/framework-symbol-list.md#classes-that-clone-themselves) has one for every class of the framework that clones itself, such as <xref:System.Text.Encoding>, <xref:System.Globalization.CultureInfo> and <xref:System.Globalization.Calendar>, and a symbol list file names a class of another library:

```text
# NonCopyableSymbols.txt: Contoso's Document clones itself in its Copy method
T:Contoso.Document;clones
M:Contoso.Document.Copy;clones
```

You get this warning in three places. The exact rule for each is in [Base Classes That Clone Themselves](../rules/declarations.md#base-classes-that-clone-themselves):

| Place | Example | Rule |
|---|---|---|
| A field that holds a non-copyable value, in a class of the project behind such a class | `private GCHandle _pinned;` in a class that derives from `UTF8Encoding` | [Fields Behind the Base Class](../rules/declarations.md#fields-behind-the-base-class) |
| A non-copyable type bound to a type parameter of such a class, where the project writes the binding | `class GuardCulture : TaggedCulture<LockGuard>` | [Bindings](../rules/declarations.md#bindings) |
| A use that lets other code clone an object whose type binds a non-copyable type | `culture.Clone()`, `CultureInfo plain = culture;` | [Uses](../rules/declarations.md#uses), and [Overrides That a Base Class Runs](../rules/declarations.md#overrides-that-a-base-class-runs) |

A use gets this warning and another ID only where it has two reasons: see [Which Warning a Use Gets](../rules/declarations.md#which-warning-a-use-gets). A `#pragma` or a suppression attribute for SCA1005 does not cover this warning.
