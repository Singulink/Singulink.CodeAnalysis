# SCA1006: Member Run on a Copy Through a Read-only Reference

Do not use a member that is not readonly through a read-only reference to a non-copyable value.

## What It Means

A member that is not `readonly` is used on a value of a non-copyable type through a read-only reference, so the compiler runs it on a copy and
what it changes is lost. For a value of a marked type parameter that is every member. See
[Read-only references and temporary copies](../concepts/read-only-references.md). Make the member `readonly`, or reach the value through
a reference that is not read-only. A conditional (`?:`), a `switch` expression and a `??` by value over a stored value give a temporary
copy, and so does a conversion that gives a value, such as the cast that unwraps a nullable. A member on one of those is reported the
same way.

## Example

```cs
void Close(in LockGuard guard) => guard.Dispose();    // SCA1006: disposes a copy

void Close(ref LockGuard guard) => guard.Dispose();   // OK
```
